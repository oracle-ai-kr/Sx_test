📋 사용 방법
1. 텔레그램에서 @BotFather → /newbot → 봇 생성
2. 받은 Bot Token 입력
3. 봇과 1:1 대화 시작 (/start)
4. 본인 Chat ID 입력
5. 테스트 메시지로 동작 확인

🌙 백그라운드 자동 알림

📊 분석 봉 TF
텔레그램은 중장기 신호 전용 (60m / 4h / 일봉).
짧은 분봉(15/30분)은 워치리스트 탭에서 사용.
⚙️ 호출 주기는 Cloudflare 워커 대시보드에서 설정 (예: */15 * * * *).
🔧 보조 필터
체크된 항목 모두 통과(AND)해야 알림. 매수 신호엔 양 방향, 매도 신호엔 역 방향으로 평가.
